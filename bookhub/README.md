# BookHub

BookHub is a platform for book enthusiasts to explore, review, and manage their personal book collections.

## Features

-   Browse a wide collection of books.
-   Add books to your watchlist.
-   Search for books by title, author, or genre.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/Eyobed9/gdg.git -b bookhub
    ```
2. Navigate to the project directory:
    ```bash
    cd bookhub
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage

1. Start the development server:
    ```bash
    npm start
    ```
2. Open your browser and navigate to `http://localhost:3000`.
