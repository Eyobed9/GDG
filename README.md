# GDG Router Project

This project is created for GDG and demonstrates a simple React application with routing using `react-router-dom` and state management using Context API. It includes multiple pages such as Home, About, Contact, Profile, and a NotFound page for unmatched routes. Additionally, it features theme toggling and authentication state management.

## Installation

1. Clone the repository:
    ```sh
    git clone <repository-url>
    ```
2. Navigate to the project directory:
    ```sh
    cd Router
    ```
3. Install the dependencies:
    ```sh
    npm install
    ```

## Usage

1. Start the development server:
    ```sh
    npm start
    ```
2. Open your browser and navigate to `http://localhost:3000`.

## Features

- **Routing**: Navigate between Home, About, Contact, Profile, and NotFound pages.
- **Theme Toggling**: Switch between light and dark themes.
- **Authentication**: Simulate login and logout functionality.

## Components

- `Home`: The home page component.
- `About`: The about page component.
- `Contact`: The contact page component.
- `UserProfile`: The user profile page component.
- `NotFound`: The component displayed for unmatched routes.

## Hooks

- `useTheme`: Custom hook for managing theme state.
- `useAuth`: Custom hook for managing authentication state.

## Dependencies

- `react-router-dom`: For routing.
- `react-icons`: For icons.
- `classnames`: For conditional class names.
